# zetel

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run start
```

To check the project:

```bash
bun run check
```

To format source files:

```bash
bun run format
```

This project was created using `bun init` in bun v1.3.13. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
